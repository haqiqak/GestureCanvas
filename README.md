# GestureCanvas
A gesture-controlled virtual interaction system for touchless drawing, teaching, and spatial UI experimentation using computer vision.

This project began as an experimental ASCII thermal renderer and is evolving into a broader gesture-driven interaction environment including touchless drawing boards, interactive teaching interfaces, accessibility-focused controls, and desktop interaction systems.

Features
Real-time webcam capture using OpenCV
Thermal-style ASCII rendering pipeline
MediaPipe-based hand tracking
Gesture recognition system
Smoothed cursor tracking
Gesture dwell and cooldown logic
Fullscreen interactive visualization
Gesture HUD and tracking overlays
Modular architecture for rapid experimentation

Current recognized gestures:

point
peace
fist
open
pinch

Vision

The long-term goal is to transform this project into a configurable touchless interaction platform where users can control digital environments entirely through hand gestures.

Planned directions include:

Interactive Gesture Environment
Cursor control
Scroll/navigation gestures
Volume and brightness control
Gesture-triggered shortcuts
Media interaction
Touchless Drawing Board
Hand-based drawing canvas
Gesture-controlled brush switching
Air-writing and annotation
Teaching/presentation mode
Color and tool selection through gestures
Gesture erasing
Accessibility & Inclusion

This project is also being explored as an accessibility-focused interface for users with mobility limitations or touch interaction constraints.

Potential accessibility applications:

Touchless educational boards
Hands-free navigation systems
Gesture-driven communication tools
Distance-based interaction systems
